
# AI Usage Report

## Project

CircleFund – Backend (Django REST Framework) & Mobile Frontend (React Native + Expo)

---

## AI Tool Used

- ChatGPT (OpenAI)

---

## Purpose

AI was used as a development assistant throughout the project to:

- Plan the implementation
- Explain Django REST Framework concepts
- Generate boilerplate code
- Debug backend and frontend issues
- Improve UI design
- Review project structure
- Generate project documentation

All generated code was reviewed, tested, and integrated manually.
